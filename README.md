# Portfolio-ArnavJoshi
Personal portfolio website built using HTML, CSS, and JavaScript with a futuristic dark UI. It showcases my background, skills, projects, experience, and interests in AI/ML, web development, UI/UX, and problem solving. Designed to reflect both technical growth and strong visual presentation.

## Overview
This portfolio was designed to represent my journey as a first-year **CSE (Data Science)** student at **VIT Chennai**.  
The website follows a **dark futuristic theme** with red highlights, glowing accents, custom cursor interaction, animated intro screens, and an immersive UI style.

The project is focused not only on presenting information, but also on creating a strong visual identity through clean layout, structured sections, and interactive elements.

## Features
- Dark futuristic UI design
- Animated intro/loading sequence
- Custom red cursor interaction
- Responsive layout
- Hero, About, Education, Experience, Skills, Services, Projects, and Contact sections
- Interactive project showcase
- Participation/experience section for hackathons, competitions, and workshops
- Smooth transitions and hover effects
